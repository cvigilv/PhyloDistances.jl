# PhyloDistances.jl on a doubling taxon ramp

Generated by `julia --project=benchmark benchmark/rampbench.jl`. 
Companion to `results.md`, which uses round taxon counts; this one uses 
powers of two, where a table whose leading dimension is a power of two 
collides in the cache and the round sizes show nothing.

Both implementations read the same Newick files from `benchmark/ramptrees/`, 
and neither timing includes parsing — only the distance computation.

**Memory is measured differently on each side**, so only the Julia column 
is reported here; see `results.md` on why the two are not comparable.

Quartet refuses trees above 477 tips, where the number of 
four-taxon subsets outgrows the 32-bit integers it counts them in, so the 
1024-taxon row has no reference to compare against.

## Environment

- Julia 1.12.6 on arm64-apple-darwin24.0.0
- TreeDist 2.14.1 | Quartet 1.3.0 | ape 5.8.1 | R 4.6.1
