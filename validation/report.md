# Agreement with TreeDist and Quartet

Generated by `julia --project=validation validation/crosscheck.jl`.

Robinson-Foulds and the quartet distance are exact counts, compared exactly 
(integers with `==`, floats bitwise). Nye similarity and Jaccard-Robinson- 
Foulds reduce to an optimal assignment solved independently on each side — 
this package over exact `Float64` costs, TreeDist over costs quantized for 
its integer solver — so those are compared to a tolerance instead; see 
`_closeenough` in `crosscheck.jl`. Values cross from R through RCall as 
machine numbers, so nothing is routed through text. Cases cover trees with 
no splits at all, maximal imbalance, polytomies on one and both sides, 
rooted against unrooted, and identical against maximally different, 
alongside random trees.

- Julia 1.12.6, TreeDist 2.14.1 | Quartet 1.3.0 | ape 5.8.1 | R 4.4.2
- Cases compared: 1140

| quantity | reference | comparison | mismatches |
|---|---|---|---:|
| `RobinsonFoulds()` | TreeDist | exact integer | 0 |
| `RobinsonFoulds(normalize = true)` | TreeDist | bitwise float | 0 |
| `InfoRobinsonFoulds()` | TreeDist | float, tolerance 1e-6 | 0 |
| `InfoRobinsonFoulds(normalize = true)` | TreeDist | float, tolerance 1e-6 | 0 |
| `QuartetDistance()` | Quartet | exact integer | 0 |
| quartet count `Q` | Quartet | exact integer | 0 |
| `QuartetDistance(normalize = true)` | Quartet | bitwise float | 0 |
| `NyeSimilarity()` | TreeDist | float, tolerance 1e-6 | 0 |
| `NyeSimilarity(normalize = true)` | TreeDist | float, tolerance 1e-6 | 0 |
| `JaccardRobinsonFoulds()` | TreeDist | float, tolerance 1e-6 | 0 |
| `JaccardRobinsonFoulds(k=2, allowconflict=false)` | TreeDist | float, tolerance 1e-6 | 0 |
| `JaccardRobinsonFoulds(normalize = true)` | TreeDist | float, tolerance 1e-6 | 0 |

`RobinsonFoulds(normalize = true)` was `NaN` in 16 cases, where neither tree carries a split and the divisor is zero.

The quartet distance counts a four-taxon subset that only one tree 
resolves as a difference, so the reference value is Quartet's `d + r1 + r2`. 
`Q`, the number of four-taxon subsets, is checked against `binomial(n, 4)` 
so that both sides agree on the divisor as well as the distance.

`JaccardRobinsonFoulds(k=2, allowconflict=false)` exercises both a non- 
default exponent and `allowconflict = false` in the same call, in addition 
to the two metrics' defaults.

Every value agrees, exactly where an exact comparison applies and to 
within tolerance where it does not.
